# Chesapeake Bay Water Quality Analysis

## Project Description

This repository contains a cleaned water-quality dataset downloaded from the Water Quality Portal for an environmental science research project.

## Dataset Information

- **Source:** Water Quality Portal (USGS and EPA)
- **Location:** Dorchester County, Maryland, within the Chesapeake Bay watershed
- **Time Period:** 2021–2022
- **Original Records:** 5,362
- **Research Focus:** Examining water-quality conditions and identifying potential environmental trends.

## Data Cleaning

The dataset was cleaned using RStudio. The cleaning process included:

- Identifying and addressing missing values.
- Detecting potential outliers using the interquartile range (IQR).
- Retaining environmentally plausible outliers.
- Standardizing measurement units.
- Correcting inconsistent text and date formatting.
- Removing columns containing no data.

## Data Source

[Water Quality Portal](https://www.waterqualitydata.us/)

## Purpose

The cleaned dataset will be used for statistical analysis of water-quality measurements and environmental conditions in the Chesapeake Bay watershed.
